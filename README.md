# HPxShinez Website

Simple React + TypeScript app built with Vite.

## Prerequisites

Install **Node.js** (includes npm):

- Download from [https://nodejs.org](https://nodejs.org) (LTS version)
- After installing, open a terminal and check:

```bash
node -v
npm -v
```

You should see version numbers for both.

---

## Mac setup

1. Open **Terminal**.
2. Go to this project folder:

```bash
cd path/to/HPxShinez-Website
```

1. Create the Vite app (when we scaffold it, or if `package.json` already exists, skip to step 4):

```bash
npm create vite@latest hpxshinez-frontend -- --template react-ts
```

1. Install dependencies:

```bash
npm install
```

1. Start the app:

```bash
npm run dev
```

1. Open the link shown in the terminal (usually `http://localhost:5173`) in your browser.

To stop the server, press `Ctrl + C` in the terminal.

---



## Windows setup

1. Open **Command Prompt** or **PowerShell**.
2. Go to this project folder:

```bash
cd path\to\HPxShinez-Website
```

1. Create the Vite app (when we scaffold it, or if `package.json` already exists, skip to step 4):

```bash
npm create vite@latest . -- --template react-ts
```

1. Install dependencies:

```bash
npm install
```

1. Start the app:

```bash
npm run dev
```

1. Open the link shown in the terminal (usually `http://localhost:5173`) in your browser.

To stop the server, press `Ctrl + C` in the terminal.
